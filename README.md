# Stillroom

A focused, browser based exam workspace built with React, Vite, and TypeScript. Import a JSON file or paste JSON generated by an LLM. Stillroom keeps exams and study progress in the browser's local exam library.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Install and study offline

Open the production site over HTTPS and use your browser's install or Add to Home Screen option. After the first online visit finishes caching the app, you can open Stillroom and use your saved exams offline. To try this locally, run `npm run build` followed by `npm run preview`.

Once downloaded, an update takes effect the next time you open Stillroom after closing its open windows. If you keep Stillroom open, **Update and reopen** saves the current attempt and opens the new version.

## Math toolbox

Open **Math toolbox** from the header to plot 2D curves and explore 3D surfaces with the embedded GeoGebra calculators. The calculators load over the internet when opened. GeoGebra is free for non-commercial use and requires a separate license for commercial use. See [GeoGebra licensing](https://www.geogebra.org/license).

## Exam JSON format

The root object describes the exam. Each question has a prompt, choices, the ID of its correct choice, a short explanation, and optionally progressive hints. LaTeX is supported in text using `$inline math$` or `$$display math$$`. Markdown is also supported.

```json
{
  "title": "Linear maps under pressure",
  "subtitle": "A short set on structure and duality.",
  "subject": "Advanced linear algebra",
  "mode": "washback",
  "pointsPerQuestion": 100,
  "questions": [
    {
      "id": "q1",
      "topic": "Invariant subspaces",
      "difficulty": "brutal",
      "prompt": "Let $T\\in\\operatorname{End}(V)$. What follows if $T$ is diagonalizable?",
      "choices": [
        { "id": "a", "text": "Its minimal polynomial is square-free." },
        { "id": "b", "text": "Its characteristic polynomial is irreducible." }
      ],
      "answer": "a",
      "explanation": "A linear map is diagonalizable precisely when its minimal polynomial has no repeated irreducible factors.",
      "hints": [
        { "label": "Nudge", "text": "Look at the minimal polynomial.", "cost": 12 },
        { "label": "Structure", "text": "Compare the exponents of its irreducible factors.", "cost": 24 },
        { "label": "Near the theorem", "text": "Diagonalizability is equivalent to a square-free minimal polynomial.", "cost": 38 }
      ]
    }
  ]
}
```

`mode` must be `washback` or `feedback`. In washback, questions unlock in sequence, each response is committed once, and each hint revealed reduces the question's maximum points by its `cost`. In feedback mode, answers can be changed and explanations appear after a choice. Questions may set their own `points`, `topic`, and `difficulty` (`gentle`, `deep`, or `brutal`).

The importer is intentionally tolerant of common LLM formatting slips: it can find the exam JSON inside Markdown fences or surrounding prose, and unwraps common response containers such as `exam`, `data`, `result`, or `output`. Unknown properties are discarded before the exam is used. Required fields and answer/choice IDs are still validated, so extra text is okay but broken exam data is not.

The prompt builder can set `hideOptionsUntilWork` to `true` so the learner writes a result before seeing multiple-choice options. On review, the app renders the correct choice first, then the reasoning and the per-distractor `choiceExplanations`. Put mathematical notation inside `$...$` or `$$...$$` delimiters for rendered LaTeX.
Written questions use `short-answer`, `free-response`, or `proof` and replace choices with a model answer and rubric:

```json
{
  "id": "q2",
  "type": "proof",
  "prompt": "Prove that if $T^2=T$, then $V=\\operatorname{im}(T)\\oplus\\ker(T)$. ",
  "expectedAnswer": "For every $v$, write $v=T(v)+(v-T(v))$. The first term lies in $\\operatorname{im}(T)$ and $T(v-T(v))=0$, so the second lies in $\\ker(T)$. If $x=T(y)$ and $T(x)=0$, then $x=T^2(y)=T(y)=x$ and also $x=0$; hence the intersection is zero.",
  "rubric": "1 point for the decomposition; 1 point showing the remainder is in the kernel; 1 point proving the intersection is zero.",
  "hints": []
}
```

The learner writes and submits a response, then sees the model answer and grading rubric and self-marks whether they met it. Written responses are not automatically graded. In the prompt studio, set an exact count for each question type; the live prompt tells the LLM the required distribution and requires a `type` field on every question. Choose the number of options for multiple-choice items separately. `hideOptionsUntilWork` applies only to multiple-choice items.
